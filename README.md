## 🔥Features

*   Gradual Turning
*   Speed levels (walk/trot/gallop)
*   Spur Mechanic
*   Horse Kicking (will damage mobs if horse rears)
*   Horse only rears if hurt by mobs (better chance to escape from fire/cacti)

# Controls
* 'W' (Forward Key) to go from walk to gallop, holding it uses mouse controls
* 'A' and 'D' to steer
* 'Ctrl' (Sprint Key) to consume 1 spur and gain a small speed boost

## 🔥Features

*   Gradual Turning
*   Speed levels (walk/trot/gallop)
*   Spur Mechanic
*   Horse Kicking (will damage mobs if horse rears)
*   Horse only rears if hurt by mobs (better chance to escape from fire/cacti)
*   Horses can swim
*   Horses can deal trampling damage when galloping into mobs

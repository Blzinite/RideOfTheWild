# 操控
* 'W' (前进键) 从慢步到跑步, 按住时使用鼠标操控马匹
* 'A' 和 'D' 控制左右转向
* 'Ctrl' (跑步键) 使用1个马刺并且短时间进入疾驰

## 🔥功能介绍

*   真实的转向
*   马匹步态 (漫步/快步/跑步)
*   刺马加速机制
*   马匹踢击(如果马匹扬起前蹄，会伤害怪物)
*   马匹仅在受到怪物伤害时才会扬起前蹄(增加从火焰/仙人掌中逃脱的机会)
*   马匹能游泳
*   马匹在疾驰状态下可以造成践踏伤害

## 🎯策划中功能

**都加上了嘿嘿嘿嘿**

*   无需马鞍 (1.21.1, 2.0.0+ 可用)
*   僵尸和骷髅马可以同样操控 (1.21.1, 2.0.0+ 可用)
*   怪物也会骑马 (1.21.1, 2.1.0+ 可用)
*   马匹体型, 大型马匹可以承载p2 (由于2.0.0版本可以用于任何马匹，可以用其他模组来实现)
